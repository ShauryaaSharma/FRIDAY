# Integrations

Friday runs with zero setup. One API key gets you a working assistant with SQLite memory,
a mock calendar and JSONL traces on disk. Everything on this page is optional — a way to
point one part of Friday at something you already use.

## The three rules

Every integration on this page obeys the same three rules, and they are worth stating up
front because they are what keeps the core readable:

1. **Opt-in.** Nothing here is on by default. A missing key means the feature is absent,
   never that Friday fails to start.
2. **Behind an extra.** Heavy dependencies install separately (`pip install -e '.[voice]'`).
   The default install is stdlib plus `anthropic` and `openai`.
3. **The loop never changes.** Gateways move text. Backends store text. `friday/loop/agent.py`
   does not know which of these you turned on.

The local default also stays the source of truth. Turning on Google Calendar adds a
write-through target; it does not delete `.friday/calendar.ics`.

## Turning one on

Three steps, the same three every time:

```bash
cp .env.example .env
```

```bash
pip install -e '.[gcal]'
```

Then uncomment the variables for that integration in `.env` and fill them in. The
`pip install` step only applies to integrations that list an extra.

To check it worked, open the dashboard and read the Connections tab:

```bash
make dashboard
```

It lists every integration, whether its variables are present, and whether a live health
check succeeds. That is the fastest way to tell "I forgot the key" apart from "the key is
wrong".

### Where things live

| What | Where |
|---|---|
| Your secrets | `.env` at the repo root — gitignored, never commit it |
| Runtime state | `.friday/` — `state.db`, `calendar.ics`, `outbox/`, `traces/` (gitignored) |
| MCP server list | `.friday/mcp.json` |
| The full variable list | `.env.example` |

`.env.example` is generated by `scripts/generate_env_example.py` from the definitions in
`friday/integrations.py`. If this page and that file ever disagree, the code is right —
regenerate and trust the output.

## Model providers

Friday speaks two wire formats, Anthropic's and OpenAI's, and every supported provider is
one of the two. Pick one with `FRIDAY_PROVIDER` and give it a key. No extra needed — both
SDKs are core dependencies.

| Provider | `FRIDAY_PROVIDER` | Key |
|---|---|---|
| Anthropic | `anthropic` | `ANTHROPIC_API_KEY` |
| OpenAI | `openai` | `OPENAI_API_KEY` |
| Gemini | `gemini` | `GEMINI_API_KEY` |
| DeepSeek | `deepseek` | `DEEPSEEK_API_KEY` |
| Kimi | `kimi` | `MOONSHOT_API_KEY` (`MOONSHOT_BASE_URL` selects the region) |
| GLM | `glm` | `ZHIPU_API_KEY` (`ZHIPU_BASE_URL` selects the region) |
| MiniMax | `minimax` | `MINIMAX_API_KEY` (`MINIMAX_BASE_URL` selects the region) |
| xAI | `xai` | `XAI_API_KEY` |
| OpenRouter | `openrouter` | `OPENROUTER_API_KEY` |
| OpenCode Zen | `opencode_zen` | `OPENCODE_ZEN_API_KEY` |
| OpenCode Go | `opencode_go` | `OPENCODE_GO_API_KEY` |

Each provider ships a default pair of models: a main model, and a small one used for the
retrieval gate and the summarizer. Override either with `FRIDAY_MODEL` and
`FRIDAY_SMALL_MODEL` — they are plain strings, so any model id the provider accepts works.
The defaults live in `PROVIDERS` in `friday/loop/models.py`.

For anything that speaks one of the two formats but is not in the table, point Friday at it
directly with `FRIDAY_BASE_URL` and `FRIDAY_API_KEY`.

## Channels

A channel is a gateway: it moves text in and text out, and that is all it is allowed to do.
Each one is a single file under `friday/gateway/`.

### Telegram

Message your laptop from your phone.

```bash
pip install -e '.[telegram]'
```

Create a bot with [@BotFather](https://t.me/BotFather), then set `TELEGRAM_BOT_TOKEN`.
Set `TELEGRAM_ALLOWED_USER` to your own numeric Telegram user id — without it, anyone who
finds the bot is talking to your assistant, with your memory and your calendar.

### Discord

```bash
pip install -e '.[discord]'
```

Set `DISCORD_BOT_TOKEN`, and narrow who can reach it with `DISCORD_ALLOWED_USER` and
`DISCORD_ALLOWED_CHANNEL`. `DISCORD_REQUIRE_MENTION=1` makes the bot answer only when it is
mentioned, which is what you want in a channel with other people in it.
`DISCORD_MAX_TURNS_PER_HOUR` is a spend cap. `DISCORD_HOME` gives the bot a memory
directory of its own, separate from your CLI Friday.

### WhatsApp

Uses the Meta Cloud API, which delivers messages by webhook — so this one needs a publicly
reachable URL, not just a laptop.

```bash
pip install -e '.[whatsapp]'
```

Create an app at [developers.facebook.com](https://developers.facebook.com/apps), then set
`WHATSAPP_TOKEN`, `WHATSAPP_PHONE_NUMBER_ID`, `WHATSAPP_APP_SECRET` and
`WHATSAPP_VERIFY_TOKEN` (the last is a string you invent; Meta echoes it back to confirm
the webhook). Restrict senders with `WHATSAPP_ALLOWED_PHONE`, digits only, no `+`.

### Voice

Speech in, speech out, running locally.

```bash
pip install -e '.[voice]'
```

```bash
make voice
```

Unset, it is push-to-talk: press Enter, speak, press Enter. Set `FRIDAY_WAKE_WORD` to any
phrase — commas separate alternatives, and near-misses are worth listing
(`friday,hey friday,fry day`) — and it becomes always-listening.

| Variable | Does |
|---|---|
| `FRIDAY_WAKE_ACK` | What it says when it wakes (default `Yes?`) |
| `FRIDAY_FOLLOWUP_SECONDS` | Stay in the conversation this long before needing the wake word again |
| `FRIDAY_WHISPER_MODEL` | `tiny` / `base` / `small` — bigger is more accurate and slower |
| `FRIDAY_TTS` | `say` (macOS built-in) or `kokoro` (local neural voice) |
| `FRIDAY_VOICE` | Voice name — `Daniel` for `say`, `bm_george` / `bm_fable` for kokoro |
| `FRIDAY_MIC_THRESHOLD` | Lower if it never hears you, higher if it wakes on room noise |

For the neural voice: `pip install -e '.[voice-neural]'`. It pulls torch, so it is a large
install; Friday detects it automatically once present.

## Calendar and productivity

### Google Calendar

```bash
pip install -e '.[gcal]'
```

Follow Google's
[Python quickstart](https://developers.google.com/calendar/api/quickstart/python) to get an
OAuth client, then set `FRIDAY_GOOGLE_CALENDAR=1` and optionally
`FRIDAY_GOOGLE_CALENDAR_ID` (defaults to `primary`).

The credentials file you download and the token it produces are both gitignored
(`credentials.json`, `client_secret*.json`, `*token*.json`). Keep them out of the repo
regardless — a leaked OAuth client is a leaked calendar.

### Apple Calendar and Apple tools

macOS only, no extra, no key — Friday drives the local apps.

- `FRIDAY_APPLE_CALENDAR=1` — read and write Apple Calendar.
- `FRIDAY_APPLE_CALENDARS` — limit it to named calendars.
- `FRIDAY_APPLE_TOOLS=1` — Apple Mail and other local tools.

macOS asks for automation permission the first time. If nothing happens and no prompt
appears, that permission was denied earlier; grant it in System Settings under Privacy and
Security, Automation.

## Memory backends

Semantic memory defaults to SQLite FTS5 — keyword search, no service, no key. Episodic
memory defaults to SQLite too. Each can be repointed with one variable.

### Semantic: `FRIDAY_SEMANTIC_STORE`

| Value | Needs | Notes |
|---|---|---|
| `sqlite` | nothing | Default. FTS5 keyword search |
| `supabase` | `.[supabase]`, `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`, `OPENAI_API_KEY` | pgvector. Run `sql/init_supabase.sql` first. `OPENAI_EMBED_MODEL` overrides the embedding model |
| `mem0` | `.[arena]`, `MEM0_API_KEY` | `MEM0_USER_ID` defaults to `friday` |
| `zep` | `.[arena]`, `ZEP_API_KEY` | Temporal graph. `ZEP_USER_ID` defaults to `friday`; `ZEP_MAX_WAIT_SECONDS` (default 120) is how long Friday waits for asynchronous ingestion |
| `langmem` | `.[arena]`, `OPENAI_API_KEY` | Without `FRIDAY_LANGMEM_POSTGRES` it uses LangGraph's in-memory store, whose data dies with the process |

The `arena` backends are hosted services that exist here so the dashboard's Memory arena
can race them against Friday's own store. They are never installed by default.

### Episodic: `FRIDAY_EPISODIC_STORE`

| Value | Needs |
|---|---|
| `sqlite` | nothing (default) |
| `notion` | `.[notion]`, `NOTION_TOKEN`, `NOTION_EPISODES_DATABASE_ID` |

Create the Notion integration at [notion.so/my-integrations](https://www.notion.so/my-integrations)
and share the target database with it — a token alone does not grant access to a page.

## Search and observability

### Web search

Set `TAVILY_API_KEY` from [tavily.com](https://tavily.com) and the search tool registers
itself. No extra required.

### Tracing

Traces always land in `.friday/traces/*.jsonl` whether or not you configure anything, and
`make dashboard` reads them from there. To also export OpenTelemetry spans to a collector
such as Phoenix or Langfuse:

```bash
pip install -e '.[tracing]'
```

Set `OTEL_EXPORTER_OTLP_ENDPOINT` to the collector's URL. `make trace` starts a local
Phoenix instance on port 6006.

## MCP servers

Any Model Context Protocol server can supply tools to Friday.

```bash
pip install -e '.[mcp]'
```

Create `.friday/mcp.json`:

```json
{
  "servers": [
    {
      "name": "fs",
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/tmp"],
      "env": {}
    }
  ]
}
```

Each server's tools register as `<server>_<tool>` and reach the agent automatically. A
server that fails to connect is skipped with a warning and Friday still starts — one broken
entry cannot take the assistant down with it.

Note the cost: every registered tool ships in every prompt. A server exposing forty tools
makes every turn more expensive and gives the model forty more ways to pick wrong. Connect
what you use.

## Troubleshooting

**Nothing changed after I set the variable.** `.env` is read at startup. Restart the
process. If you exported the variable in a shell instead, remember it only applies to that
shell.

**The Connections tab says a variable is missing that I set.** You probably edited
`.env.example` rather than `.env`. Only `.env` is read.

**The key is present but the health check fails.** That is the integration answering, so it
is a credentials or permissions problem, not a wiring one — an expired token, a database
not shared with the integration, a region-specific base URL left at its default.

**An optional import fails at startup.** The extra is not installed in the environment you
are actually running. Confirm with `pip show <package>` inside the same virtualenv.

**I want to see exactly what ran.** Every turn writes a trace to `.friday/traces/`. Open it
in the dashboard, or read the JSONL directly — it is one line per event, deliberately.
